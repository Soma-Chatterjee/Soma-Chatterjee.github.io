## 💻 Local Preview

To preview the website locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Soma-Chatterjee/soma-chatterjee.github.io.git
   cd soma-chatterjee.github.io
   ```

2. **Open `index.html`:**
   * Simply double-click `index.html` in your file explorer, or
   * Serve with VS Code **Live Server**, or run via terminal:
     ```bash
     npx serve .
     ```
